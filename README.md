## 压缩包获取

| 项目 | 说明 |
| --- | --- |
| 文件 | `qp3.zip`（仓库根目录，Git LFS 存储） |
| 大小 | 237,614,534 字节（约 226.6 MB） |
| 条目 | 3276 个，解压后约 260 MB |
| SHA-256 | `765f689042fe879f2b278669b6478dfbc3fcff90e8bee05a39d67239c41d1ae0` |

因 GitHub 单文件硬上限为 100 MiB，本文件以 **Git LFS** 形式入库：仓库树里看到的是 LFS 指针，
网页端可直接点 Download 获取真实文件。

### 下载方式

```bash
# 方式一：git clone（需先安装 git-lfs）
git lfs install
git clone https://github.com/feifan-coder/qp3.git

# 方式二：不装 git-lfs，直接下载
curl -L -o qp3.zip https://media.githubusercontent.com/media/feifan-coder/qp3/main/qp3.zip
```
